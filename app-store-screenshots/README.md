# CareNest App Store Screenshots

Local generator for five iPhone App Store screenshots based on the existing repo captures.

## Assets in use

- `public/mockup.png`: copied from the installed `app-store-screenshots` skill
- `public/screenshots/admin-dashboard.png`: sourced from `.maestro/screenshots/04-admin-settings.png`
- `public/screenshots/employee-dashboard.png`: sourced from `.maestro/screenshots/03-admin-assign.png`
- `public/screenshots/client-dashboard.png`: sourced from `.maestro/screenshots/03-client-home-Secure Shift Messaging.png`
- `public/screenshots/invoice-list.png`: sourced from `.maestro/screenshots/05-client-home-invoices_dashboard.png`
- `public/screenshots/invoice-detail.png`: sourced from `.maestro/screenshots/06-client-invoice.png`

## Important

- `public/app-icon.png` is currently a temporary placeholder copied from the repo.
- Replace it with the attached blue/cream caregiver icon before the final export.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`, adjust theme/size, then export the PNG set.
